# V10 — v_get_pixel: Rückgabeformat Palette gegen Truecolor

Status: **OFFEN** · Priorität: **P1** · Typ: Geräteunterschied / Test

Abhängigkeiten: Keine

## Begrenzter Auftrag

Nur Bedeutung von INTOUT[0]/[1] bestimmen: Pixelindex/Mapping bei Palette, Null plus Rohwort bei Truecolor. Schwarz-Fälle 270/272 nicht allein wegen 15/1 gegen 0/0 als Fehler behandeln.

## Abnahme

Format beider Profile belegt; Schwarzprüfung getrennt von Weiß-/Overlayproblem V11.
