# FS15 — Geraetenamen `CON:`, `AUX:`, `PRN:` bei `Fopen`/`Fcreate`

Status: **OFFEN** · Prioritaet: **P3** · Typ: fehlende Funktion — Nebenfund PROC04-Re-Validierung (2026-10-18)

EmuTOS bildet die Namen `CON:`, `AUX:`, `PRN:` (auch klein) in `Fopen`/`Fcreate`
auf die Zeichengeraete-Handles ab (`references/emutos/bdos/bdosmain.c:101-110,651-663`).
In `tos-api/src` gibt es dafuer keinen Zweig (Researcher, nur gelesen).

Betroffen: QED drucken (`sdk/apps/qed/src/prn_out.c:171-173`, `wp-print.c:401`),
mintlib `unx2dos.c:61` (`tty:` → `con:`).

Auftrag: Spec aus EmuTOS, bauen, Hosttests; Test mit `Fopen("CON:")` +
`Fwrite`.

[Gemeinsame Regeln](README.md) gelten.
