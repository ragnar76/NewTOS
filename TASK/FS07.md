# FS07 — `Fseek` auf einem Konsolen-Handle liefert `EIHNDL`, EmuTOS 0

Status: **OFFEN** · Prioritaet: **P2** · Typ: Abweichung von EmuTOS — Nebenfund der E9-Nacharbeit ([ARCH03](ARCH03.md))

## Sachverhalt (Agent, nicht vom Lead nachgelesen)

EmuTOS `bdos/bdosmain.c:571-641`: `Fseek` auf einem Zeichengeraete-Handle
liefert 0. NewTOS liefert `EIHNDL`. Wirkung: baut man die libc ueber mintlibs
`_main`, scheitert jede Ausgabe ueber `stdout` mit `EBADF` (9 Laeufe in
`measurements/measurement-2026-10-06-post-e9/diag-libc-main/`).

## Arbeit

EmuTOS-Stelle lesen, Spec `docs/api/gemdos/` pruefen/ergaenzen, angleichen,
Test fuer Konsolen-, PRN- und AUX-Handle.
