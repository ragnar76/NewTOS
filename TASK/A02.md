# A02 — wind_get(0, WF_CXYWH): geräteabhängige Geometrie absichern

Status: **OFFEN** · Priorität: **P2** · Typ: Geräteunterschied / Test

Abhängigkeiten: Keine

## Begrenzter Auftrag

Nur WF_CXYWH auf Handle 0 prüfen. Erwartung aus Gerätemaßen: (0, 0, W, H). Bestehende Tests zuerst prüfen; nur fehlende Eigenschaft ergänzen. Keine Änderung auf TT-Konstanten.

## Abnahme

Beide Profile 640×480 und 1920×1080 erfüllen die Regel; ein falscher W/H-Wert wird erkannt. Keine zusätzliche Hardwareauflösung implementiert.
