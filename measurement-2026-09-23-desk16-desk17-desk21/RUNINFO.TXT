0. What each ticket asked, and what the source said
---------------------------------------------------

DESK16 -- confirmed and built. `icon.rsc` really does carry eight enabled
  `ICONBLK`s; `icons.c` (the C EmuTOS generates from it with `ird`) shows
  `icon_rs_iconblk[5]` = `rs_icondata5` over **`rs_iconmask0`** -- the
  removable disk has no mask of its own, it shares the hard disk's. The seven
  rasters NewTOS already had were re-verified byte-for-byte against the same
  file before the eighth was added.

DESK17(1) -- confirmed and built. `men_update` counts `ntrash` beside `ndesk`
  and disables *Delete* while a trash or printer icon is selected
  (`deskmain.c:496-535`).

DESK17(2) -- REFUTED by the source, no change. The ticket expected EmuTOS to
  release the menu title *before* the dialog runs. It does not:
  `hndl_menu` calls `menu_tnormal(desk_rs_trees[ADMENU], title, 1)` **after**
  the `do_*menu` handler has returned (`deskmain.c:1012-1038`) -- so in EmuTOS
  too the title stays inverted for as long as the dialog is up, and that is
  the classic GEM contract (the AES leaves the title highlighted; the
  application un-highlights it when it is done acting on the selection).
  NewTOS's `desk/main.rs:912-933` already does exactly this, at exactly that
  place. `screendumps/ico-B-dialog.png` in
  measurement-2026-09-24-desk03-desk04, which the ticket cited as the defect,
  shows conformant behaviour. Both halves are re-measured here anyway
  (before *and* after, dialog open *and* closed) so the finding is on record.

DESK21 -- confirmed and built. `BACKGRND` is object 46 and the **last child**
  of the View drop-down box (object 34, `ob_head` 35 / `ob_tail` 46,
  `desk_rsc.c:446,473-483`); the Options box is object 47 and starts at
  `IICNITEM` (48) -- `desk_rsc.h:35-48`. `SEP_VW2` (45) is the separator in
  front of it. `shortcut_mapping[]` needed no change: it has carried
  `BACKGRND` as the last *View* slot all along (`deskmain.c:211-217`), which
  is what the ticket meant by "semantic, not positional".
