# NewTOS - Why and How
- It started more than 20 years ago - the day I registered newtosworld.de
- The dream back then: TOS on an ordinary PC.
  - No Raspberry Pi, no ARM desktops - just a beige box and an idea
- It never got built. I couldn't program, and I never found anyone to do it with me
- This year that finally changed: I built it together with Claude, an AI
- What came out is not an emulator - it is TOS itself, rewritten for today's hardware
  - Same GEMDOS, BIOS, XBIOS, VDI and AES, checked line by line against EmuTOS
- Atari programs are recompiled from their original sources, without changes
- Since May: 1,250 commits, 190,000 lines of code, more than 1,250 tests

# What it runs on
- Raspberry Pi 4 (BCM2711, ARM Cortex-A72, 1.5 GHz)
- HDMI: up to 1920 x 1080, true colour
- SD card: 4-bit bus, multi-block transfers, ~10 MB/s
- 32 MB block cache, read in RAM after the first access
- USB keyboard and mouse
- Serial console for debugging
- MMU: every program gets memory protection, like FreeMiNT
- Develop and test in QEMU, run on the real Pi

# BIOS and XBIOS
- BIOS: console, character devices, Rwabs, Getbpb, Mediach
- Drives C: to F: from the SD card partitions (FAT)
- System variables and cookie jar as on a Falcon (TOS 4.04)
- XBIOS: screen, palette, Keytbl, Kbdvbase, Supexec, timers
- Keyboard layouts: German and US, loadable KEYBOARD.KBD
- 200 Hz system timer (_hz_200), mouse moves while programs compute
- NewTOS extensions via Ssystem: CPU clock, temperature, system info

# VDI, AES and Desktop
- VDI: about 70 functions, Falcon true-colour model
- Checked pixel by pixel against real TT and Falcon dumps
- AES: all 11 managers - windows, menus, dialogs, events, resources
- 3D look as in TOS 4 / EmuTOS
- Desk accessories (.NAC), e.g. System Info
- Desktop: EmuDESK rebuilt 1:1 - TeraDesk runs on top

# Toolchain
- clang / LLVM for AArch64, own SDK
- mintlib, gemlib, cflib ported - not rewritten
- Native 64-bit programs: .NAP (GEM), .NCP (console), .NAC (accessory)
- .PRG/.TOS/.ACC stay reserved for a future 68000 emulator
- Running ports: QED, TeraDesk, zView with 10 image codecs, Doom, CoreMark
- LDG libraries load natively (.NLD), WinDom, libpng, libjpeg, zlib
- CoreMark: about 7,300 on the Pi 4

# Plans and Outlook
- A 68000 emulator, so your old .PRG files run too

- Networking
- Faster graphics: the VDI drawing code in hand-written ARM assembly
- More software: Thing, HighWire, the newer zView
- And one day NewTOS inside a real Atari, on a PiStorm
- Follow along at newtosworld.de
