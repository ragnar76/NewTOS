# `Initmous` — XBIOS 0x00

> Phase 00 spec. Source: EmuTOS @ `1a7484ab` —
> `bios/mouse.c:40` (`Initmous`).

## EmuTOS source (essence)

```c
void Initmous(WORD type, struct param *param, PFVOID newvec)
{
    switch (type) {
    case 0: ikbd_writeb(0x12); break;            /* disable mouse */
    case 1: /* relative mode + threshold */ ...   break;
    case 2: /* absolute mode + scale + initial */ break;
    case 4: /* keycode mode */ ...                break;
    /* type 3 / >4 ignored */
    }
    if (newvec != NULL) kbdvecs.mousevec = newvec;
}
```

The function configures the IKBD's mouse-packet behaviour by
sending command bytes via `ikbd_writeb` and optionally hooks the
caller's mouse-packet handler into `kbdvecs.mousevec`.

## Outputs

`void`. D0 == 0 from dispatcher default.

## Errors

None — invalid `type` is silently ignored.

## Edge cases

### 1. `param == NULL`

Types 1, 2, 4 require `param`; if NULL the configuration commands
are not sent and the IKBD keeps its previous mode. Type 0 ignores
`param`.

### 2. `vec == NULL`

`kbdvecs.mousevec` is left untouched. Programs commonly call
`Initmous(0, NULL, NULL)` first, then re-call with their handler.

### 3. Reset side effect

Type 0 sends IKBD command `0x12` ("disable mouse") — the IKBD
stops sending mouse packets entirely. AES sets type 0 on exit to
revert to a clean state.

### 4. Type 3 not implemented

EmuTOS comments mark type 3 as reserved; calling with type 3 is
a silent no-op. Compendium documents type 3 as
"set Y=0 at bottom" (Atari-Doc) — a discrepancy worth noting.

### 5. IKBD command serialisation

`ikbd_writeb` blocks until each byte is sent. Type 2 sends ~16
bytes — measurable latency (~2 ms on hardware ACIA). NewTOS
without IKBD chip has no transmission delay.

is not implemented in EmuTOS. Defer logging until a real program
is found that uses it — most code just toggles types 0/1/2.

## Configuration

## NewTOS implementation notes

(Empty during Phase 00.)

PHASE-07: NewTOS interprets the IKBD command bytes generated by
`Initmous` and configures the USB-HID-mouse translator (relative
vs absolute, scaling, initial position). Mouse packets are
synthesised in IKBD-compatible format and dispatched through
`kbdvecs.mousevec` exactly as on Atari hardware.
