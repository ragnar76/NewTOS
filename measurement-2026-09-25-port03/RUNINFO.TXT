0. WHAT WAS SWAPPED
---------------------------------------------------------------------------
sdk/cflib is no longer pinned by "version" but by COMMIT:

  github.com/freemint/cflib, ce57817c3f68c7d346d1081768505e81acaee807
  ("Replace last remaining tho-otto.de references with my server", 2026-07-14)
  packed with `git archive --prefix=cflib-21/ ce57817 | xz -9`
  -> sdk/cflib/cflib-21-ce57817.tar.xz
     sha256 8427502d6a309864cfd4621201d032d04b512dddeb8f59eff33eca545683ed8e

It replaces the previous sdk/cflib/cflib-21.tar.xz, which was NOT a 2004
tarball: it is byte-identical to the tho-otto mirror's SOURCE snapshot
download/mint/cflib-21.tar.xz of 2024-04-30,
sha256 7f0d69f43f450df1f0a4699bda8738f5d8f7cc31257e0db531b8e8ba4062e349.
cflib has never raised its 0.21.0 version number since 2004, so the number in
VERSION/ChangeLog says nothing about the state of the sources. The real gap
was 13 commits, of which four touch compiled files: fsnorm.c (2ac3e85),
fsexists.c (af02175 + cdb1fdf), fexists.c (cdb1fdf), fontsel.c (399f7a6).

The mirror was checked for a dated alternative and has none that carries the
fixes: /snapshots/cflib/*.tar.bz2 are m68k BINARY dev packages (usr/lib/**/
libcflib.a, usr/include, stguide), zero .c files.


1. FIXTURE (method/seed.sh)
---------------------------------------------------------------------------
On top of the standard image:
  C:\QED.NAP + C:\qed.rsc   QED (current build) at the ROOT
C:\README.TXT (64 bytes) is the dragged file; it is on the standard image, as
is C:\Apps\TERADESK\.
QED normally lives in C:\Apps\QED\; it is copied to the root so the acceptance
gesture is one drag inside ONE window (identical drop path, `fun_win2win`,
kernel/src/desk/dir.rs:1793) -- the same arrangement PORT01 used.

The TeraDesk run (method/seed-tera.sh) takes that same card and replaces
C:\NEWDESK.INF with the #Z autorun line (method/newdesk-tera.inf, unchanged
from measurement-2026-09-21-t04).


2. INJECTOR (method/t10_workaround.py)
---------------------------------------------------------------------------
a78_patch2.py's dual arming picks the empty SCRIPT_TERA whenever an EL0
process is the running one at the first injector tick, and since the
accessories landed that is always the case (TASK/T10.md, still OPEN).
t10_workaround.py replaces the dual arming with the one case needed here:
step only once "[desk] desktop up" has set DESK_UP, and always run
SCRIPT_DESK. The shared harness is left untouched.

In the TeraDesk run the #Z autorun starts TeraDesk INSTEAD of our desktop, so
DESK_UP is never set and the injector never arms -- measured in a first
attempt whose log stops at "[shell] sh_ldapp: starting
C:\APPS\TERADESK\DESKTOP.NAP" with no [h02] line. That run's screendump is
therefore triggered on that kernel line plus a 45 s settle, not on a mark.

5. RESULT: the acceptance case
---------------------------------------------------------------------------
screendumps/qed-c-open.png -- QED opens the dropped file. The window title is
`C:\README.TXT`, the FULL name (qed-c-open-title-zoom.png is a 3x crop that
shows this is the rendered text), and the file's two lines are in the window.
Before the swap the same gesture produced QED's alert "Fehler beim Lesen der
Datei: README.TX" (measurement-2026-09-25-port01/screendumps/after-d-qed.png).

The chain, unchanged on QED's side: cflib `make_normalpath` now keeps the `\`
it appended (upstream 2ac3e85), QED strips exactly one separator
unconditionally (src/poslist.c:53-54), and what is left is the whole name.
QED's source was not touched.


6. RESULT: the other cflib paths
---------------------------------------------------------------------------
screendumps/qed-d-fsel.png -- Ctrl-O opens cflib's OWN file selector
("Dateien oeffnen", filesel.c) with Directory C:\*.* : the seven directories
(ACC, APPS, AUTO, CLIPBRD, COREMARK, GEMSYS, SUB) are listed AS directories
and the files (ARGVTEST.NAP, BIG.NCP) as files. That is the visible proof
that the rewritten path_exists/file_exists -- which now probe with Fsfirst
and read `Fgetdta()->dta_attribute` instead of calling Fattrib -- work on our
kernel. The DTA path holds because mintlib's `_DTA` is the packed 44-byte
layout with _Static_assert'ed offsets against makbuf (ADR-020,
sdk/libc/mintlib/include/mint/ostruct.h:85-101) and Fgetdta returns a full
64-bit x0 through __newtos_trap0.

screendumps/tera-b-up.png -- TeraDesk, relinked against the new cflib.a,
comes up with its own menu bar and its colour icons.
