---------------------------------------------------------------------------
  NewTOS's vq_scrninfo answer equals the Enhancer's in 272 of 273 words.
  The one differing word is the one the spec makes different:

      work_out[14]   Enhancer 0000   NewTOS 0002   (E3: Falcon bit order;
                     the Enhancer is EdDI 1.00, [14] only exists from 1.10)

  Outside the 273 words, as the spec decided:
      cookie value   Enhancer 00023EC0 (dispatcher address)
                     NewTOS   00000001 (E2: non-callable marker, odd)
      dispatcher(0)  Enhancer d0 = 0100; NewTOS: not called (probe skips odd)
      CONTRL[2]/[4]  Enhancer leaves both (5A5A); NewTOS writes 0 / 272
                     (the dispatcher rewrites the counts on every call;
                     272 is the documented CONTRL[4], spec 3.1)
  Same in both: INTOUT[273..511] untouched, PTSOUT untouched.
  Full word-by-word table: COMPARE.TXT (method/compare.py).

2. OBSERVED (what the bytes say)
---------------------------------------------------------------------------
* Cookie jar via _p_cookies (0x5A0 -> 0x5F0, the per-process mirror):
  NTOS 00000100, _MCH 00050000, _IDT 0000112F, _AKP 00000000,
  EdDI 00000001; terminator value 16 (mirror capacity).
* vq_scrninfo: format 2, clut 2, 16 planes, colours 0000/8000, line bytes 0,
  address 0, r/g/b 5/5/5, alpha 0, genlock 1, unused 0, [14] = 2; red bits
  11..15, green 6..10, blue 0..4, genlock bit 5, rest of 16..127 = -1,
  128..272 = 0.
* Pixels (section 4): v_get_pixel gives INTOUT[0] = 0000, INTOUT[1] = the
  word (white FFDF, red F800, green 07C0, blue 001F) -- the same pair EmuTOS
  Falcon-TC gives WITHOUT the Enhancer (the Enhancer run shows FFDF/FFFF
  there; not part of this ticket). The device-format MFDB bytes are the
  same words stored little-endian (DF FF, 00 F8, C0 07, 1F 00), so the
  probe's "BEwords" lines read byte-swapped on NewTOS. Read as the CPU
  reads them (native u16) they are FFDF/F800/07C0/001F -- the words the bit
  tables describe (E3: "bit numbers describe the pixel word as the CPU reads
  it"). Restore VERIFIED.
