NEW SSYSTEM MODES (scalars: arg1 = LONG pointer or 0, arg2 must be 0)
  2003 S_NEWTOS_CPUMEAS    ARM clock measured, Hz          (Host, mailbox, live)
  2004 S_NEWTOS_CPUPOLICY  0 firmware / 1 fixed max / 2 max refused (Host)
  2005 S_NEWTOS_MEMPROT    0 off / 1 on / 2 strict          (bdos memprot)
  2006 S_NEWTOS_ASID       0 off / 1 on / 2 test (asid=tiny) (bdos mmu)
  2007 S_NEWTOS_SDMODE     0 fast / 1 compatibility          (Host, emmc)
  2008 S_NEWTOS_SDBUS      1 / 4 bits negotiated             (Host, emmc)
  2009 S_NEWTOS_BCACHE     cache arena KiB, 0 = off          (bios bcache)
  2010 S_NEWTOS_BCACHEPCT  percent; ERROR without cache      (bios bcache)
  2011 S_NEWTOS_STRAM      ST-RAM pool KiB                   (bdos mem init)
  2012 S_NEWTOS_TTRAM      TT-RAM pool KiB, 0 = none         (bdos mem init)
  2013/2014/2015           framebuffer width/height/bpp      (Host::screen)
  2016 S_NEWTOS_GPUMEM     VideoCore memory KiB              (Host, boot answer)
  2017 S_NEWTOS_KEYBOARD   0 US / 1 German / 2 KEYBOARD.KBD / 3 changed (Host, keymap)
  2018 S_NEWTOS_SERIAL     0 off / 1 on                      (Host, console)
  2019 S_NEWTOS_KVERSION   string "NewTOS 0.1 <date> (<rev>)" into buf/len
  Unknown on a board -> ERROR, nothing written; 2020 -> EINVFN.
