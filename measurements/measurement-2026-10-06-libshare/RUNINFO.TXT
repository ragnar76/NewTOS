HOST TEST (checks/libshare-host.txt, 15/15)
  sdk/libshare/tests/libshare-host.sh: the overlaid libshare sources against
  a model of ldg_Malloc/ldg_Free with owners and an owner-based Pterm:
  module run (exit: stderr then stdout buffer, malloc(1024)+free each) ->
  first buffer inside static_mblock, no system block for it; the static block
  is then dropped from the list (libshare malloc.c:271-289); second buffer
  from ldg_Malloc owned by the module, returned with ldg_Free before the
  Pterm; after the Pterm no free-list node in freed memory; client-context
  malloc(0x46c0) from ldg_Malloc owned by the client; calloc zeroes,
  realloc keeps contents.
  Sensitivity (checks/libshare-host-sensitivity-no-static-block.txt): the
  same harness on a scratch copy with the static block disabled fails 6 of
  15 -- the static-block checks are not vacuous. The "no dangling node after
  Pterm" check passes there too: libshare's free() returns an empty hunk
  (no `q &&` in its merge-before test), whereas libc's mintlib 0.60.1 free()
  does not merge the last chunk (`if (q && s >= r ...)`,
  sdk/libc/mintlib/mintlib/malloc.c:190), which is why the B2 hunk stayed
  referenced.
