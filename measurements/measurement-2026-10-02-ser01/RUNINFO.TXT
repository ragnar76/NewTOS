measurement-2026-10-02-ser01 -- SER01 serial output off by default on board-rpi4
Date 2026-10-02, branch desk-rebuild, HEAD c1f504c + the uncommitted SER01
change-set in the shared tree. QEMU 11.0.2, machine raspi4b (and virt).

WHAT IS TESTED
  board-rpi4 keeps UART0 transmit silent unless the firmware command line
  (cmdline.txt on a real Pi; QEMU's -append on raspi4b) contains the token
  serial=on. The kernel reads the command line with the VideoCore mailbox tag
  0x00050001 "Get command line" (references/circle/lib/koptions.cpp:52-61,
  include/circle/bcmpropertytags.h:72). Panic / fatal-exception output is
  always sent (console::force_serial_tx_on).
