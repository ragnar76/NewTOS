M07 -- the proof that nothing already measured moved.  2026-09-13.

Every dump ever taken is bound to its case table by the table's CRC32, which
the dump header carries.  A change that made an existing table parse
differently, or that changed one byte of the records a re-run produces, would
invalidate the lot -- including the irreplaceable real-TT references under
tosdump/reference/.

M07 moves the refusal for six opcodes from the OPCODE to the PARAMETERS, and
it moves it in BOTH directions: two opcodes that were refused outright become
issuable for one stated arm each (25, 53), and four that were waved through
become refused unless their parameters make them safe (41, 55, 80, 81).  A
loosened guard is the more dangerous half of that: if a line that is refused
today were accepted tomorrow, an existing table containing such a line would
start producing a DIFFERENT dump from the same file.  That is checked below
rather than asserted.

Checked four ways, the same four M05 and M06 used.

5. THE HOST SUITE, AND THE TWO TESTS THAT CHANGED ON PURPOSE
--------------------------------------------------------------------------
`make -C tosdump all` -> exit 0: all six dumpers build (DUMPVDI/DUMPAES/
DUMPRAST, .PRG and .NAP) and the host suite passes.

Three assertions in tests/test_cases_aes.c were changed, and each is a
policy change with a citation rather than a test bent to fit the code -- the
same kind of edit M06 made when it moved the version-gated opcodes:

  refused("25 ... evnt_multi")   removed from the opcode list; opcode 25 is
  refused("53 ... form_error")   now refused per parameter, which the new
                                 test_parameter_guard_reads_the_values
                                 asserts for mask 0, a non-zero timer count,
                                 a missing MU_TIMER, IN_LEN below 16, and
                                 every n <= 63.
  accepted("55 ... form_keybd")  removed from the safe list; opcode 55 with
                                 no addr_in column hands a poisoned tree
                                 pointer to a call that may follow it.

Two tests were added, 45 assertions between them, both directions:
test_parameter_guard_reads_the_values and test_parameter_guard_covers_
preludes.
