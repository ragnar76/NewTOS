index became a relocated pointer table.  Regression evidence, 2026-09-14.
MEASUREMENT ONLY: this directory states what ran and what came back.

  tools/mkrsc.py                   convert() emits NRSC v7 (LP64) / v8 (ILP32):
                                   the tree index holds PTR-wide root-OBJECT
                                   byte OFFSETS (relocated by the loader) in
                                   place of fixed 4-byte root indices, and is
                                   padded so the OBJECT array stays naturally
                                   aligned.
