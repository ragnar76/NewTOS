4. REPRODUCIBILITY (decision: fixed crate metadata, no strip; checks/u912-repro.txt, checks/u912-clean-build-*.txt)
   Cause found: cargo's -C metadata of a path package OUTSIDE the workspace root hashes its absolute path -- tos-types
   (../tos-types from programs/); every dependent hashes its deps' values. Symbol hashes come from it, and codegen orders
   functions by symbol name: NEWDESK.NAP built in the shared tree vs a copy at another path differed in 5106 file bytes,
   815 of them in the LOADED image (objcopy -O binary) -- function order, not only .symtab. So stripping cannot fix it;
   an extra `-C metadata` cannot either (rustc hashes all of them). Fix: rustc wrapper replacing cargo's value by a hash of
   name+version+crate-name+crate-type+target+cfgs. Proof: clean build (fresh copy + .git, no target/) at
   /tmp/m5j/u912/clean/an-other-path: rpi4 kernel8.img 0 differing bytes vs bin/kernel8-u912.img, qemu-virt flat image 0,
   NEWDESK.NAP and HELLOGEM.NAP of both boards 0 (method/clean-build.sh).
