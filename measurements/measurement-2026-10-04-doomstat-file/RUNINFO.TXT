CHANGE
  doomgeneric_gem.c: every "DOOM..." line of the platform layer goes through diag(). DOOM_GEM_STATS == 0:
  `#define diag printf` (shipped build byte-identical, below). DOOM_GEM_STATS > 0: the line goes to the
  console exactly as before (vprintf) and is also appended to DOOMSTAT.TXT in the current directory,
  CRLF-terminated (a trailing \n or \r becomes \r\n). Plain GEMDOS: the first line of a run Fcreates
  (truncates) the file, each further line is Fopen(write) + Fseek(end) + Fwrite + Fclose. GEMDOS has no
  flush call and updates the directory length only at Fclose, so "flush after each line" is done as
  close-per-line; no handle is left open, nothing to close at exit. A failing open/write stops the file
  for the run and says so once on the console. main() adds one FILE-ONLY line "DOOM: arguments: ..." so
  the zone request (-mb) is recorded; the engine's own "zone memory: ..." line (i_system.c, vendored, not
  editable) stays console-only.
