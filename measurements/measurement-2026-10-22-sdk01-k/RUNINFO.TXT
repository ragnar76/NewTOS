measurement-2026-10-22-sdk01-k -- TASK/SDK01 package K: Rust out of the C path
==============================================================================

WHAT
  sdk/toolchain.sh resolves ld.lld / llvm-ar / llvm-nm / llvm-readobj /
  llvm-objdump / llvm-size per tool: NEWTOS_<TOOL> -> NEWTOS_LLVM_BIN -> PATH
  -> clang's real directory -> Homebrew opt/llvm, opt/lld -> /usr/lib/llvm-*
  -> pinned Rust nightly (rust-lld, llvm-tools-preview) as the last fallback.
  NEWTOS_TOOLCHAIN=auto|llvm|rust. newtos_lld adds -flavor gnu only for
  rust-lld/lld. All SDK build scripts, sdk/build.sh, sdk/vendor-lib.sh, the
  three host tests that link (rt-host, ldbl-host, libc-link) and
  sdk/bin/newtos-cc (new: --toolchain) use it. Kernel path (cargo xtask)
  untouched.

HOST
  Apple Silicon Mac, macOS 27, Apple clang 21.0.0 (clang-2100.3.34.2),
  Rust nightly-2026-04-15 (LLD 22.1.2). NOT installed: Homebrew llvm, lld;
  no container runtime (docker/podman/colima/lima all absent).

METHOD  (method/)
  build-all.sh <label>   deletes the 13 SDK archives, runs 27 build scripts
                         (libc gemlib cflib libm compiler-rt ldg zlib libpng
                         libjpeg giflib libexif windom libshare qed teradesk
                         hypview zview coremark doom gemtest chaintest present
                         apitest fsbench libtest ldg-client ldg-demo), sdk/build.sh,
                         newtos-cc -bare / -lm, both templates via newtos.mk,
                         started from OUTSIDE the checkout; sha256 of every
                         produced .a/.NCP/.NAP/.NLD (64 files: 13 archives,
                         51 program files).
  probe-resolution.sh    14 lookup-order / error-path cases.
  conv.pl                the mechanical script edit ($BIN/... -> newtos_tool,
                         "$LLD" -flavor gnu -> newtos_lld).
  "LLVM on PATH" was simulated: scratch dir fakellvm/ with ld.lld -> the
  pinned toolchain's rust-lld binary (lld picks the GNU flavour from argv[0],
  as a distribution's ld.lld symlink does) and llvm-* -> the sysroot's tools.
  "No Rust": env -i, PATH=<rustc trap>:/usr/bin:/bin:/usr/sbin:/sbin:fakellvm
  -- no ~/.cargo/bin; rustc/rustup on PATH are trap scripts that log every
  call and fail.
