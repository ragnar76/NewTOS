measurement-2026-10-13-libc-tty -- TASK/LIBC-TTY decision 1: the NewTOS isatty shim
(sdk/libc/newtos-arch/isatty.c, fds 0-2 = tty, __open_stat[].flags never set) is deleted;
mintlib's own mintlib/isatty.c is built again (Fcntl TIOCGPGRP -> EINVFN, then the Fseek
probe; flags CRMOD|ECHO for a tty). Analysis: docs/analysis/libc-tty-2026-10-13.md.

6. OBSERVABLE BEHAVIOUR CHANGES for libc programs (source: mintlib main.c/read.c/open.c)
   * stdin on the console reads through Fread (line read with echo and editing, CR -> \n
     plus Cconout('\n')) instead of the RAW Crawcin path (no echo, two keys per byte,
     fgets never ended).
   * stdout/stderr redirected by the parent (Fforce to a file): isatty = 0 -> stdout fully
     buffered, binary mode (no LF -> CRLF; fstat still reports S_IFCHR, TASK/LIBC-FSTAT),
     and _main's Fforce(2,-1) is skipped when handle 2 is a file.
   * isatty(-1) = 1 (was 0); every open() costs Fcntl + up to 3 Fseek traps more.
   * write() goes bytewise with CRLF only with RAW set or a SIGINT handler installed; no
     program in sdk/apps installs one (grep).
