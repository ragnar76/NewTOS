DESIGN (tos-api/src/bdos/process/memprot.rs, module docs "Tables")
  Rights stay COMPUTED, NOT UPDATED: an event only names the pages and the
  slots whose descriptors may change; sync recomputes those from the pool
  lists, owners, records and E10 grants (FreeMiNT mark_region shortcut,
  references/freemint/sys/arch/mprot040.c:1102-1130).
  * Dirty entry = range + slot mask + `shared` (non-owner pattern may change
    -> every live slot) + `privates` (every slot holding a private L3 copy of
    the region). Entries are merged only with equal mask/flags; full list ->
    the two closest entries merge (superset = only more work).
  * on_alloc: pages were free -> shared only for PROT_G/PROT_PR, holders only
    if the mode gives owners access.  on_freed / on_released (Mshrink tail,
    aligned-allocation slack): shared as above, holders via `privates` (a
    slot whose view differed from the non-owner pattern has a private copy,
    or kept the non-owner rights after a table shortfall).  set_mode: nothing
    for the same mode or PROT_P<->PROT_S (identical descriptors); otherwise
    shared/holders only where the owner/other flags change.
    on_owner_change_by(loc, cookies): only the slots that reach the block
    THROUGH the owner cookies that came/went (their memory space + E10
    holders); nothing for PROT_G/PROT_I.  region.rs and set_owner pass the
    cookies; the old on_owner_change(loc) stays as conservative path
    (holders now + privates), used by on_resident's non-PROT_P branch.
  * Structure changes as a per-block difference of holders before/after:
    on_root_built (only the new root is rebuilt completely), set_space
    (Pexec(4) joins a memory space; pexec::go stores space_pd through it),
    on_slot_released (slots that reached the dying slot's blocks), E10
    grant/revoke. on_launch only adds the E5 inherited blocks of the child.
  * Safety: memprot remembers (root, basepage, space) per slot (SEEN); a
    change that went past the announcing functions is caught at the next
    sync and answered with a complete rebuild of every live slot (stage-3b
    behaviour), counted as `fallbacks` (0 in every kernel run below; the
    host test of an unannounced space change sees 1).
  * memprot::batch(): Pexec load / go / create, Pterm's sweep, the aligned
    allocations defer their syncs to the end of the guard; install_ttbr0 and
    the trap end use sync_now (always). Nothing inside a batch runs at EL0 or
    touches user memory through the user tables (loader writes via kernel
    alias; audited: loader.rs, pexec.rs, pterm.rs, traps.rs paths).
  * Refresh per region: blocks from one sorted snapshot per sync (binary
    search), page loops only for the shared table (if `shared`) and for
    visited slots that need a private copy; a slot that no longer needs one
    drops it (drop_private, BBM, ASID-aware as before). Every changed leaf
    still goes through mmu::set_leaf (TLB_DIRTY / owed per-VA invalidation
    with ASIDs), table switches through make_private/drop_private (BBM) --
    TLB maintenance unchanged.
  * Verification mode: boot argument memprot=verify (kernel), set_verify
    (host tests; panics there). After every sync with work, and after any
    rights event even if it decided nothing changes, verify_now() recomputes
    every pool page of the shared tables and of every live slot's view with
    the stage-3b algorithm, written separately (own MD walk, rec_of,
    further_owners, live_slot_of, group_masks), and checks private copies
    exist exactly where a slot's rights differ (shortfall slots tolerated and
    counted). Differences: "[memprot] VERIFY MISMATCH ..." at the trap end;
    counters "[memprot] verify: ..." after each process end and every 256
    checks.

  allocation touches only its owner's tables; Mshrink <= 512 descriptors

  slots; a batch (allocate as caller, set mode, hand to child) syncs once and
